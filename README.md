A one-line pickup line, spoken by a vending machine to a passing human, for the
[One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee)
on make.fun. The machine's coil has been jammed all week — until one look at a
passer-by makes everything in it want to drop.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt`.
